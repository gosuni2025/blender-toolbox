# UV Pixel Transform 0.2.0

UV 섬을 이미 칠한 그림과 함께 이동·확대·회전하는 Blender 애드온입니다.

[최신 설치 ZIP 받기](https://github.com/gosuni2025/uv-pixel-transform/releases/latest)

## 사용법

1. **UV Editing**에서 모델을 **Edit Mode**로 바꾸고 편집할 이미지를 표시합니다.
2. UV 섬을 선택하고 **N → UV + Pixels**를 엽니다. 일부만 선택해도 연결된 섬 전체가 대상이 됩니다.
3. **Language → 한국어**를 선택하면 Blender 전체 언어를 바꾸지 않고 애드온만 한국어로 쓸 수 있습니다.
4. 이동·확대·회전 버튼을 누르고 마우스를 이미지 영역으로 가져옵니다.
5. 임시 레이어를 조작합니다. 도중에 **G / S / R**로 이동·확대·회전을 이어서 할 수 있습니다.
6. **Enter 또는 왼쪽 클릭**으로 한 번에 적용하거나 **Esc 또는 오른쪽 클릭**으로 취소합니다.
7. **Image → Save**로 텍스처를 저장한 뒤 `.blend`도 저장합니다.

확정 전에는 GPU로 떠 있는 레이어만 그립니다. 원본 이미지와 실제 UV 좌표, 3D 모델의 머티리얼은 바뀌지 않습니다. 다른 그림 위에 겹쳐 보거나, 이미지 밖으로 꺼내 크기와 회전을 조절한 뒤 다시 가져올 수 있습니다. 영구적인 레이어 스택은 아니며, Enter로 적용할 때 이미지에 합성됩니다.

## 옵션

| 옵션 | 설명 |
| --- | --- |
| 적용 시 원래 자리 지우기 | 기본 꺼짐. 켜면 적용할 때만 원래 그림을 투명하게 지웁니다. 꺼두면 기존 그림이 남습니다 |
| 이미지 밖에서도 조작 | 기본 켜짐. 바깥에서도 그림이 보입니다. 선택한 섬 전체가 이미지 안에 들어와야 적용할 수 있습니다 |
| 적용 시 다른 UV 섬 보호 | 기본 켜짐. 미리보기는 겹쳐도 되지만 적용 시 덮어쓰기는 막습니다. 끄면 다른 섬 위에도 합성할 수 있습니다 |
| 그림 미리보기 | 끄면 임시 UV 윤곽만 표시합니다 |
| 가장자리 여백 | 적용 시 섬 가장자리 색을 0~16픽셀 연장합니다 |

원래 자리가 투명해진 것은 **적용 시 원래 자리 지우기** 옵션의 결과이며 별도의 붙여넣기 단계는 없습니다. 취소하면 원본을 유지하고, 적용 후에는 **Ctrl+Z**로 UV와 그림을 함께 되돌립니다.

## 보간 필터

- **최근접:** 색을 섞지 않아 픽셀 아트에 적합합니다.
- **바이리니어:** 기본값. 주변 픽셀을 부드럽게 섞습니다.
- **바이큐빅:** Catmull–Rom 필터로 더 선명하게 보간합니다.
- **Lanczos:** 3-lobe Lanczos 필터. 선명하지만 강한 경계에 링잉이 생길 수 있습니다.

미리보기와 적용에 같은 보간 커널을 사용합니다. 반투명 색 번짐을 줄이기 위해 알파를 고려해서 계산합니다. 확대만으로 원래 없던 세부 묘사가 생기지는 않습니다.

## 단축 조작

- 조작 중 **G / S / R**: 이동 / 배율 / 회전 전환
- **X / Y**: 이동축 고정
- 숫자 입력: 이동은 픽셀, 배율은 `1.5` 같은 배수, 회전은 도 단위
- **Ctrl**: 스냅 / **Shift**: 미세 조정
- **휠·트랙패드·마우스 가운데 버튼**: 조작 중에도 화면 확대·축소·이동. 뷰를 바꿔도 레이어 변환은 유지됩니다.
- 예: 이동 버튼 → `X → 20 → Enter`로 오른쪽 20픽셀 이동
- 예: 이미지 밖으로 이동 → `S`로 배율 → `R`로 회전 → `G`로 이미지 안으로 복귀 → `Enter`

일반 Blender G/R/S는 애드온을 시작하기 전에는 원래 기능대로 동작합니다.
