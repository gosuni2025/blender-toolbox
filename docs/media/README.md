# Demo media

The project owner supplied a 30.38-second, 1920×1080, 60 fps development recording for publication in this repository.

- `demo.mp4`: H.264, 1280×720, 24 fps, CRF 26, fast-start, no audio.
- `demo.gif`: 960×540, 12 fps, 128-color palette, looping, no audio.

The recording shows v0.1.1. The current extension additionally supports floating GPU previews, off-canvas transforms, four filters and six UI languages. The media and depicted artwork are separate from the extension's source-code license.
